Optional filter: minimum System Point separation (OFF by default)

When ON, a new entry or stop-and-reverse is NOT taken while the latest confirmed Top and Bottom are closer than the threshold (index points). Exits are never blocked and no System Point is changed. It can reduce reversal storms, but it can also skip real moves. Results with the filter ON are NOT the original strategy results.
